Support

Support

For help with any Monolyn Labs product, email support@monolyn.nl.

Please avoid sending sensitive personal data. Most apps are offline-first and do not require accounts.

What to include

  • Product name (and where you installed it from)
  • App version
  • Device model + OS version
  • Steps to reproduce (1–5 steps)
  • Screenshots or screen recording (if relevant)

Response time

We aim to respond within 2 business days.

Security issues

Report a security issue
Security

If you believe you found a security issue, email security@monolyn.nl with SECURITY: in the subject line.
A machine-readable security policy is available at /.well-known/security.txt.
