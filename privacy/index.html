Privacy Policy

Effective date: 2026-01-24

Monolyn Labs builds offline-first iOS apps and lightweight Jira Cloud tools. We aim to collect as little data as possible, and we do not use third‑party trackers.

1. Website (monolyn.nl)

This website is a static site hosted on Cloudflare Pages. We do not run analytics scripts, advertising pixels, or third‑party tracking.

  • No cookies for analytics are set by this site.
  • Server logs: like most hosting providers, Cloudflare may process basic request logs (e.g., IP address, user agent) for security and delivery.

2. Support email

If you email support@monolyn.nl, we receive the contents of your message and any attachments. Our support inbox uses standard email providers (e.g., Gmail) to receive mail.

  • Use this only for support requests. Do not send sensitive personal data.
  • We retain support emails only as long as needed to resolve the request and for basic record‑keeping.

3. iOS apps

Our iOS apps are designed to work offline and typically store data locally on your device. We do not require an account to use the core functionality.

  • No third‑party tracking SDKs are intentionally integrated.
  • Local data: any content you create in the app stays on your device unless you export/share it.
  • Crash diagnostics: Apple may provide crash reports depending on your device settings. If such reports are available to us, they are used only to improve stability.

4. Jira Cloud apps

Our Jira apps run inside your Atlassian Cloud environment (e.g., via Atlassian Forge). These apps only access data necessary to provide the feature, and data handling is subject to Atlassian’s platform controls.

5. Changes

If we materially change this policy (for example, by adding analytics), we will update this page and adjust the effective date.

6. Contact

Privacy questions: security@monolyn.nl.
